# Administrator localization keys

The `admin` namespace has now been registered in the localization Spreadsheet. The complete 144-row implementation inventory, with Korean, Japanese, English and Mongolian translations, is recorded in [localization-rows.tsv](./localization-rows.tsv). Status is TRANSLATED, not REVIEWED. Production JSON is generated from the Sheet, not from this document.
