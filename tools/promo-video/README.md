# Trasolve 75초 소개 영상 (v9, FHD 60 FPS)

Python 3, Pillow, NumPy, FFmpeg, Noto Sans CJK TTC가 필요합니다.

```sh
python -m pip install -r requirements.txt
python render_v9.py --preview
python render_v9.py
```

영상은 `Trasolve_75s_v9.mp4`에 저장됩니다. 환경 변수 `TRASOLVE_FONT_REGULAR`, `TRASOLVE_FONT_BOLD`로 폰트 경로를 지정할 수 있습니다. `TRASOLVE_FONT_INDEX`(기본값 1)로 TTC 인덱스를 변경할 수 있습니다. Windows/macOS에서는 설치된 폰트 경로를 지정하세요.

서비스의 npm 빌드와 독립적으로 실행됩니다. 최종 MP4와 `work/`의 렌더링 결과는 Git에서 제외합니다. 원본 캡처의 지도 출처 표시는 유지하세요.

## v9 변경 사항

- 0–8.5초에 장소 검색과 “어떤 순서로 방문해야 하루를 효율적으로 보낼 수 있을까요?”라는 질문을 별도 장면으로 배치합니다.
- 8.5–22초에 구글 지도와 네이버 지도의 일반 길찾기, 여행자가 정해야 하는 방문 순서, 영업시간·체류시간·이동시간을 고려하는 Trasolve를 차례로 소개합니다.
- 40–45초에 팀의 11월 시연 녹화본 `route.mp4`를 사용합니다. 실행 버튼부터 최종 결과까지의 약 12초를 5초로 편집했습니다. 탐색 대기 구간을 빠르게 재생하며, 지도에 나타나는 중간 경로는 서비스의 탐색 미리보기입니다.
- 편집한 5초 소스는 `assets/route-optimization.mp4`에 포함되어 있습니다. 렌더링할 때 사이트 로그인이나 원본 영상이 필요하지 않습니다. `--preview`는 장면별 미리보기를 `work/v9_contact.jpg`에 저장합니다.

## v8 변경 사항
- 60 FPS로 렌더링하고 화면 캡처 확대의 4단위 양자화를 제거해 이동을 부드럽게 처리.
- 4–8초 구간을 단순 경로 설명에서 구간 길찾기와 미결정 방문 순서의 비교 장면으로 변경.
- 일반 길찾기는 구간 안내만 제공하고 여행 전체의 방문 순서는 직접 정해야 한다는 메시지를 명시.
- 다른 장면, 75초 타임라인, 오디오를 유지. `render_v7.py`는 이전 버전 재현을 위해 보존.

## v7 변경 사항
- Google 지도와 네이버 지도의 일반 구간 길찾기가 여행 조건에 맞는 방문 순서를 정해주지 않는다는 점을 명시.
- Trasolve는 구간 길찾기는 물론 방문 순서까지 최적화한다는 비교 카피를 브랜드 등장 및 최적화 도입부에 반영.
- v6의 75초 타임라인, 모션, 실제 캡처 및 음악을 유지. `render_v6.py`는 이전 버전 재현을 위해 보존.

## v6 변경 사항
- 중앙 타이포그래피, 전체 화면 연결 그래픽, 가로형 조건 카드, 좌우 캡처 비교, AI 오비탈 그래픽 등 장면별 레이아웃을 분리.
- 지도 노드 번호 변경과 방문 카드 재배치, 실제 캡처의 슬로우 푸시인, 강조 테두리, 채팅 타이핑, 슬라이드·디졸브 전환.
- 75초, FHD 30 FPS 및 기존 자체 제작 음악 유지. v5의 실제 캡처와 오디오 생성 함수를 재사용하며, 새 서비스 촬영이나 AI 편집 동작의 실시간 검증은 하지 않음.
- `render_v5.py`는 이전 버전 재현 및 공통 유틸리티를 위해 유지.

## v5 변경 사항
- 도입부에 Google 지도·네이버 지도의 구간 길찾기와 여행 조건을 고려한 방문 순서 계산의 차이를 명시.
- 하단 진행 바와 우측 상단 페이지 번호, 제작용 보조 문구 제거.
- 75초 타임라인, 음악, 실제 캡처 및 디버그 수치 가림 유지.

## 사용 자료

- 지도 그래픽, 카드 애니메이션과 AI 일정 편집 흐름은 연출용으로 생성합니다. AI 편집 동작은 이번 영상에서 새로 검증하지 않았습니다.
- 원본 로고 대신 서비스명 타이포그래피를 사용합니다.
